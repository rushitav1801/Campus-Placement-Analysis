# Campus-Placement-Analysis

A predictive classification model on the campus placement of an XYZ university by studying the academic background and work experience

- Libraries used: Numpy, Pandas, Scikit-learn, Matplotlib, Seaborn
- Dataset downloaded from: [Campus Recruitment Data](https://www.kaggle.com/datasets/benroshan/factors-affecting-campus-placement)
  
The report contains the entire explanation of the problem statement, insights derived and other conclusions drawn 

Link to the notebook in Kaggle: [Kaggle notebook](https://www.kaggle.com/code/rushitav/campus-recruitment-eda)
